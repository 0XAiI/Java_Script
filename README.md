# Simple Web Calculator

A clean, responsive web-based calculator built using HTML, CSS, and vanilla JavaScript.

## Features

- **Basic Arithmetic Operations**: Perform addition (+), subtraction (-), multiplication (*), and division (/).
- **Clear Functionality**: Easily clear the display input using the `C` button.
- **Error Handling**: Displays `Error` if an invalid mathematical expression is entered.
- **Modern UI**: Styled with dark mode aesthetics, rounded buttons, grid layout, and interactive hover/active states.
