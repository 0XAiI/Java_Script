A clean, minimalist, and responsive web-based calculator constructed with plain HTML, CSS Grid, and vanilla JavaScript.

## Features

- **Standard Operations**: Supports basic arithmetic including addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **Clear Display**: Quick reset using the `C` key.
- **Error Handling**: Gracefully handles invalid syntax by displaying an `Error` state.
- **Modern UI**: Styled with a dark theme, CSS grid layout, rounded buttons, and interactive visual feedback for hover and active states.
