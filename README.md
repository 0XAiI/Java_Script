# Simple Web Calculator

A clean, responsive web-based calculator built using HTML, CSS, and vanilla JavaScript.

## Features

- **Basic Arithmetic Operations**: Perform addition (+), subtraction (-), multiplication (*), and division (/).
- **Clear Functionality**: Easily clear the display input using the `C` button.
- **Error Handling**: Displays `Error` if an invalid mathematical expression is entered.
- **Modern UI**: Styled with dark mode aesthetics, rounded buttons, grid layout, and interactive hover/active states.

## Project Structure

├── index.html   # Markup for calculator layout and buttons
├── index.css    # Layout, grid system, colors, and button styling
└── index.js     # JavaScript logic for DOM manipulation and calculations

## Getting Started

1. Clone or download the repository.
2. Ensure `index.html`, `index.css`, and `index.js` are in the same folder directory.
3. Open `index.html` in any modern browser to use the calculator.

## Usage

- Click any number or operator button to append it to the display screen.
- Click `=` to compute and evaluate the expression.
- Click `C` to reset the display screen.
